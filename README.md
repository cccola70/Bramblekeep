# Bramblekeep

A cute, fully-animated real-time roguelike built as a single self-contained HTML file — no build step, no dependencies. Open `index.html` in a browser to play.

Bump-combat your bunny knight through 15 floors across three realms (Bramblekeep, the Shadowfen Forest, and the Sunken Shoals), each ending in its own boss. Find weapons (sword, spear, axe, hammer) and armor sets with visible gear changes, level up through a card-based ability system, spend persistent Shards on permanent skill trees between runs, and bank your progress or push deeper after every boss.

Everything — sprites, animation, dungeon generation, particles, and sound — is drawn and synthesized in plain JavaScript and Canvas 2D.
